What it does not do

  • It never approves, blocks or releases a payment. A person in Accounts Payable decides every case.
  • It has only seen synthetic invoices from a fictional company (CFS). Scores on real invoices will differ.
  • Category reading uses a keyword list plus each vendor's past claims, so an unusual description from a new vendor can be misread.
  • An unusual amount on its own scores below the default threshold. Lower the threshold to see the trade: more catches, more false alarms.
  • Live use in an SBP-regulated institution needs an approved environment, encryption, access control and audit logs (SBP BPRD Circular No. 01 of 2023) first.
